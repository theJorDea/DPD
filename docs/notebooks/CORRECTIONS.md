# Исправления BlackBox spline-memory notebook

Дата полного проверочного запуска: 2026-08-06.

## Итоговое научное решение

Предложение заменить BlackBox DPD на ветви `((0,0),(1,0),(2,0))` не было
принято без проверки. Эта топология использует одну текущую амплитуду во всех
ветвях:

\[
z[n]=\sum_{m=0}^{2}x[n-m]C_m(|x[n]|).
\]

На frozen BlackBox PA evaluator она дала cascade NMSE от `-11.402` до
`-12.111 dB` для `K={4,8,12,16,24,32}`, то есть хуже режима без DPD
(`-16.010 dB`). Поэтому она сохранена в notebook как отклонённая абляция.

Для этого capture выбрана проверенная топология согласованных задержек:

\[
z[n]=\sum_{m=0}^{2}x[n-m]C_m(|x[n-m]|),
\]

или `((0,0),(1,1),(2,2))`. Она не объявляется универсально лучшей и не
подменяет основную DPA/APA архитектуру проекта.

## Что исправлено

1. Добавлены явные этапы: идентификация и заморозка PA evaluator, затем
   калибровка и deployment-like проверка DPD.
2. Зафиксирован правильный путь `desired x -> DPD -> frozen PA -> output`;
   измеренный `y_val` не используется как вход DPD при итоговой проверке.
3. Уточнён статус: это отдельный BlackBox capture, не DPA/APA и не физическое
   измерение PA после DPD.
4. Добавлено предупреждение о встроенной копии измеренных данных и создана
   внешняя версия без payload.
5. Добавлены train-only integer alignment, fractional-delay diagnostic,
   normalization и complex gain. Validation не переоценивает эти параметры.
6. Удалена псевдо-EVM. Нормированная временная RMS-ошибка явно отмечена как
   математически эквивалентная pooled NMSE в dB; стандартная QAM EVM не
   заявляется.
7. Выполнено сравнение двух топологий и `K={4,8,12,16,24,32}`. Правило выбора:
   минимальная модель в пределах `0.01 dB` от лучшего validation NMSE. Оно
   выбирает `K=24`; `K=32` лучше только на `0.00626 dB`.
8. График неоднородного отношения `D(x)/x` заменён на отдельные `Re C_m`,
   `Im C_m`, `|C_m|` и фазу каждой ветви, а также на векторное разложение одного
   отсчёта `z[n]=u0+u1+u2`.
9. PSD оставлена только как сглаженная Welch-диагностика в циклах на отсчёт.
   ACLR/ACPR не вычисляется без известных sample rate и границ полос.
10. Убрано визуальное сравнение real MUL нашего DPD с количеством параметров
    OpenDPD. Стоимость теперь вычисляется из выбранных ветвей и `K`.
11. Усилены проверки фазовой эквивариантности, направления DPD, chunked
    streaming и reset состояния между независимыми records.
12. Fixed-point результаты DPA/APA не переносятся на BlackBox; notebook честно
    помечен как float-only.
13. Все итоговые значения формируются полным запуском и выводятся в начале и
    конце notebook.

## Результаты полного запуска

- PA evaluator fidelity: `-28.590 dB` pooled complex NMSE на validation.
- Frozen PA без DPD: `-16.010 dB` cascade NMSE.
- Выбранный spline-memory DPD: `-17.192 dB` cascade NMSE.
- Улучшение: `1.182 dB` по мощности нормированной ошибки.
- Конфигурация: `((0,0),(1,1),(2,2))`, `K=24`, ridge `1e-4`.
- Fast path: `27 real MUL`, `28 real ADD`, `3` вычисления амплитуды,
  `15` сравнений и `6` чтений LUT на комплексный отсчёт.
- Хранение: `72` комплексных (`144` вещественных) коэффициента и `2`
  комплексных отсчёта состояния.
- Максимальная ошибка проверки фазовой эквивариантности: `2.483e-16`.
- Ошибка цельной и chunked обработки: `0.000e+00`.

Validation использовалась для model selection. Эти числа не являются
независимой sealed-test оценкой и подтверждены только через frozen PA evaluator.

## Воспроизведение

Из корня проекта:

```bash
MPLCONFIGDIR=/tmp/dpd_mpl_config python experiments/build_blackbox_dpd_notebook.py
```

Для внешней версии установить `USE_EMBEDDED_DATA=False` и указать `MAT_PATH`
либо `SELECTION_DIR`. Для MAT требуются SciPy и комплексные массивы `x`, `y`,
`eRef` одинаковой длины.
