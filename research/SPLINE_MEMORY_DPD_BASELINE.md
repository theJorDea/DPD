# Зафиксированный baseline: Spline Memory DPD

## Модель

Для BlackBox зафиксирована причинная фазово-эквивариантная модель

\[
z[n]=\sum_{m=0}^{2}x[n-m]C_m(|x[n-m]|).
\]

Конфигурация:

- ветви `((0,0),(1,1),(2,2))`;
- 24 квантильных узла на ветвь;
- комплексные кусочно-линейные сплайны;
- ridge `1e-4`;
- ILA-калибровка `y/g -> x` только по train;
- deployment-like validation `x -> DPD -> frozen PA evaluator`;
- validation не является независимым sealed test.

## Зафиксированный BlackBox результат

В зафиксированном BlackBox benchmark:

- no DPD: `-16.00477 dB` pooled cascade NMSE;
- Spline Memory DPD: `-17.19093 dB`;
- выигрыш относительно no DPD: `1.18616 dB`;
- frozen GMP PA fidelity: около `-28.59 dB`.

Небольшое отличие от чисел подробного notebook (`-16.010/-17.192 dB`)
обусловлено использованием производственного `baseline.gmp_pa` вместо
локальной notebook-реализации solver. Это не другой физический эксперимент.

## Стоимость рабочего тракта

- 27 real MUL/complex sample;
- 28 real ADD/complex sample;
- 3 вычисления амплитуды;
- 15 сравнений;
- 6 чтений LUT;
- 144 вещественных коэффициента;
- 4 вещественных значения состояния.

Это аналитическая стоимость, а не измеренный hardware timing.

## Правило дальнейшей работы

Эта конфигурация остаётся неизменным baseline. Каждый новый кандидат должен:

1. использовать тот же split, gain, normalization и frozen evaluator;
2. сравниваться с этим baseline, а не только с no DPD;
3. публиковать отрицательные результаты;
4. проходить segment-wise проверку;
5. не переноситься в основной notebook до доказанного улучшения;
6. не называться физическим результатом до измерения одного и того же PA.
